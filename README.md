# 🏪 7-ELEVEN 門市月營收 AI 智慧回推系統看板原型 (Web Prototype)

> **專案名稱**：7-11 超商門市營收預測專案（零售門市月營收 AI 智慧回推模型）  
> **業師指導**：工研院服務系統科技中心 馬大程 博士  
> **版本號**：v8 雙層模型架構成果展示版  

---

## 📌 1. 專案背景與目標

統一超商（7-ELEVEN）僅在財務報告中公開全台單月合併營收總額，**單一門市的月營收屬商業機密，無公開數據**。

本專案運用 **AI 兩層模型分配演算法**，將台灣 7-11 本業當月目標總營收（以 62% 份額計算約 189.84 億元），依全台 **7,313 間門市**周邊的空間、人口、競品與商圈 POI 特徵進行科學化智能分配，並透過 Bootstrap 抽樣輸出每間門市的 **80% 信賴區間**。

---

## 🚀 2. 快速啟動說明 (Quick Start)

只需要執行以下任一方式即可開啓互動看板：

### 方法一：一鍵啟動 (推薦)
在終端機中切換至本資料夾並執行：
`ash
python launch_server.py
`
伺服器將於 http://localhost:8711 啟動並**自動開啟瀏覽器**。

### 方法二：直接雙擊或用 Python 伺服器
`ash
python -m http.server 8711
`
隨後在瀏覽器開啟 [http://localhost:8711](http://localhost:8711) 即可。

## 🎨 3. 看板核心功能與展示亮點

本 Web 看板專為審查簡報 (M1/M2/M3) 及成果展示 (Demo Day) 設計，具備以下互動功能：

1. **🔍 全台 7,313 間門市即時搜尋與篩選**
   - 支援店名、門市 ID、地址關鍵字模糊搜尋。
   - 提供「縣市」與「鄉鎮市區」兩級下拉連動篩選。
   - 支援依估算營收高低排序與店名排序。

2. **💰 門市月營收與 80% Bootstrap 信賴區間展示**
   - 視覺化條狀圖顯示門市月營收估計值（如台北市中山區森鑽門市估算約 **770 萬元/月**；偏鄉門市約 **5 萬元/月**）。
   - 誠實揭露 **80% Bootstrap 信賴區間（上限與下限）**，展現模型不確定性。

3. **🎛️ 台灣本業營收份額敏感度即時切換**
   - 提供 **60% / 62% (標準採納) / 65%** 三種集團合併營收切換情境，所有門市金額即時重新演算。

4. **🧠 AI 雙層演算法特徵拆解**
   - **層一（Ridge 迴歸）**：顯示地區租金基準分與 Ridge 迴歸全域係數貢獻（如自家門市密度 +0.234、競爭店數 +0.145）。
   - **層二（PCA + 熵權法）**：顯示店內相對分數與特徵權重比較（PCA 重視人口戶數；熵權法重視生活與交通 POI）。

5. **✅ 合理性驗證結果卡片**
   - 展示所得中位數外部驗證結果（**Spearman $\rho = +0.219$,  < 0.001$**）。
   - 特別說明**資訊防火牆 (Information Firewall)** 機制：所得資料全程未參與訓練，驗證具備高度獨立性。

6. **🏆 全台門市營收排行榜**
   - 一鍵切換檢視全台 **TOP 5 高營收門市** 與 **底部 5 低營收門市**。

7. **⚠️ Zero POI 待人工核對專區**
   - 特別標記全台 37 家周邊 POI 數據為零的邊緣門市，提供線上核對與實地稽核彈窗。

## 📊 5. 核心模型參數摘要

| 項目 | 設定值 / 結果 | 說明 |
|---|---|---|
| **門市總數** | 7,313 間 | 涵蓋全台灣 22 縣市 7-ELEVEN 門市 |
| **分配目標金額** | 189.84 億元/月 | 2026 年 6 月合併營收 $\times$ 62% 台灣本業份額 |
| **層一演算法** | Ridge Regression | Y = 鄉鎮坪租金，學習地區商業行情基準 |
| **層二演算法** | PCA + 熵權法 (Entropy) | 學習門市周邊人口/POI/競品之店級相對強弱分數 |
| **外部驗證指標** | Spearman $\rho = +0.219$ | 控制人口後之殘差與所得中位數呈現統計顯著正相關 ( < 0.001$) |
| **信賴區間** | 80% Bootstrap CI | 重複抽樣計算每間門市之營收不確定性上下限 |
